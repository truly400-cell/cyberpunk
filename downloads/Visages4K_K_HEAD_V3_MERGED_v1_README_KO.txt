Visages4K + K_HEAD_V3 합본 v1

구성
K_HEAD_V3의 얼굴형/눈/치아/메이크업/사이버웨어 모프12개,
피부 재질01_ca_pale.mi와 고유 눈 텍스처를 유지합니다.
피부 텍스처10개는 Visages4K 원본을 사용합니다.
겹치는6개(얼굴 diffuse d01~d05와 기본 normal n01)는 Visages판으로 선택합니다.
K_HEAD의 원래 피부 칠과 기본 노멀에 의한 음영은 Visages 쪽으로 바뀝니다.
K_HEAD의 고유 피부 재질 설정은 유지합니다.
이 합본은 두 피부 스타일을 픽셀 단위로 혼합하는 작업이 아니라,
K_HEAD 형태에 Visages 피부 텍스처를 적용하도록 리소스 선택을 고정한 것입니다.

설치
1. 게임을 종료합니다.
2. 아래 원본3개를 모두 끄거나 게임 폴더 밖으로 옮겨 백업합니다.
   !!!!!!!!!!!!!!!!_Arkhe_09_UST_Visages_01_Base_4k.archive
   !_Arkhe_09_UST_Visages_01_Base_4k.archive
   !!!!!!!!!!!!!!!_K_HEAD_V3.archive
   모드 매니저에서는 Visages 원본과 K_HEAD_V3 원본을 비활성화합니다.
3. 합본 .archive 하나를 Cyberpunk2077/archive/pc/mod/에 넣습니다.
   원본 모드의 의존성/캐릭터 생성 설정은 기존대로 유지합니다.
4. 게임을 다시 실행합니다. 여성V 리소스를 대상으로 하는 합본입니다.

Visages의 느낌표가다른2파일은 SHA256까지 완전히 같은 중복입니다.
함께 켜도 서로 다른 기능이 추가되지 않습니다. 합본 사용 시 둘 다 제거/비활성화합니다.

검증
분할7z복원/압축해제와 내부ZIP CRC 검사를 통과했습니다.
원본Visages10개, K_HEAD20개, 중복경로6개를 비교하여 합본24개를 만들었습니다.
공식 WolvenKit8.18.0으로 패킹/재추출하고,24개 모두 선택한 원본과 바이트 일치를 확인했습니다.
아카이브 리소스 경로 해시도 두 입력의 합집합과 같습니다.
원본 .morphtarget/.mi/.xbm 파일 내부는 재인코딩하지 않았습니다.
K_HEAD 기본 모프의 노멀 참조/텍스처 차이 메타데이터도 확인했습니다.
실제 게임 로딩/외형/조명은 이 환경에서 검증하지 못했습니다.
K_HEAD 원본과 완전히 같은 피부 음영까지 유지된다고 보장하지 않습니다.
